# Claude Code project instructions

Read and follow @AGENTS.md and @docs/COLLABORATION.md before working in this repository.

Codex and Claude use separate worktrees. Preserve Codex's branch, files, processes and output assets just as Codex must preserve Claude's. Check the shared ownership notes and the other worktree's status before taking overlapping files. Do not overwrite either agent's work when integrating.

These instructions apply when this file is present in your checkout. Existing Claude sessions should explicitly reload the shared rules after they are integrated; a copy on another branch is not automatically active here.
